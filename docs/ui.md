# 看板界面约定

看板给 Yi 一个人用，但按「第一次打开、不看说明书也能用」来写。改界面前先读这一页。

## 视觉

- **颜色**：`src/styles.css` 的 `:root` 变量。中性色是暖灰；唯一强调色是黛绿 `--accent`，只给主操作、选中态、等你处理的事。`--ok / --warn / --bad` 只做小面积状态（标签、圆点、一行错误字），不做大块底色，也不给按钮。`--zhu` 是旧名，等同强调色，新代码不用。
- **字号**只有四档：12（辅助信息、标签）、14（正文、按钮、输入框）、16（抽屉和弹窗标题）、20（页面标题、指标大数）。Tailwind 写 `text-[12px] / text-[14px] / text-[16px] / text-[20px]`，不要 11、12.5、13、15、17、22。层级靠字重（400 / 600）和颜色（text / text-2 / muted）拉开。
- **圆角**：4（标签、小块）、6（按钮、输入框、筛选）、10（卡片、列表、抽屉里的分组）；圆点和计数用 999。嵌套时内圆角 = 外圆角 − 间距。
- **阴影**：只给真正浮起来的抽屉、弹窗、提示条。页面里的卡片、列表是平的，用 1px `--line` 分隔，不套卡片。
- **字体**：等宽字体（`code` / `.code`）只用于代码、命令、路径、分支、cron、工单号这类要逐字比对的标识。数字不用换等宽字体，加 `tabular-nums`（`.num`）对齐即可。不用斜体、不全大写，少用 `·` 串内容（能分开放就分开放）。
- **危险操作**：不标红。按钮用普通样式；真正不可逆的（删除、放弃改动、执行写操作）弹一次确认，确认框里写清后果。

## 文案

- 称呼用「你」，不用「我」。说人话，不出现内部名词：Worker、tier、路由、轮询、看门狗、agent、effort、session、pending 这类词不进界面，换成下面的说法。
- 一句话能说清就不写两句；界面本身（按钮、空状态、分组名）能表达的不再加说明。说明文字不加括号补充一大串。
- 动词不催促：不用「立即」「马上」「赶快」。

## 数字

统一用 `src/lib/format.ts` 和 `src/components/ui.tsx` 里的函数，不在组件里自己 `toLocaleString` 再截字符串（月、日位数会变，截出来会错）。

- 时间点：`when(ts, now)` → 今天 14:05、明天 09:30、11月12日 09:33；只要时刻用 `hm(ts)`；完整时间（悬停提示、详情）用 `time(ts)` → 2026年11月9日 14:05；只要日期用 `date(ts)`。
- 多久以前：`ago(now, ts)` → 刚刚、5 分钟前、3 小时前，超过一天给具体日期。
- 时长：`span(sec)` → 3 分钟、2 小时 5 分钟；耗时用 `dur(sec)` → 0.8 秒、12 秒。单位用中文，数字和单位之间空一格，不写 3m、2h05m、12s。
- 钱：`money(usd)` → $1.98；不到一分钱写 <$0.01，不写 $0.0012。
- 大数：`compact(n)` → 1.3万、340万（中文按万、亿进位，不写 K、M）。
- 百分比：`pct(x)` → 37%，并写清是什么的百分比（「已用 37%」而不是孤零零的 37%）。
- 数字和中文之间空一格（3 个提交、第 2 轮），百分号、货币符号紧贴数字。
